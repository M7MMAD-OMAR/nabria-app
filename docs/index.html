05

Choose your distro.

The packages include the app and transcription engine. Setup downloads only the model that fits your machine.

sudo dnf install https://github.com/M7MMAD-OMAR/nabria-app/releases/latest/download/nabria.rpm
Fedora and dnf-based distributions
wget https://github.com/M7MMAD-OMAR/nabria-app/releases/latest/download/nabria.deb && sudo apt install ./nabria.deb
Debian, Ubuntu and apt-based distributions
git clone https://github.com/M7MMAD-OMAR/nabria-app.git && cd nabria-app/packaging && makepkg -si
Available from the AUR
curl -fsSL https://github.com/M7MMAD-OMAR/nabria-app/releases/latest/download/install-nabria.sh | sh
